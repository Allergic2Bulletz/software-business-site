# Software business site

A simple, one-page starter site for a software business class.

## Make it yours

1. Open `index.html` in this repository and select the pencil icon to edit it.
2. Replace the business name and sample text with your own details.
3. Commit your changes to `main`. GitHub Pages will publish the updated site after a short delay.

The site is public. Do not include private information or credentials.

To preview changes on your computer, open `index.html` in a browser.
